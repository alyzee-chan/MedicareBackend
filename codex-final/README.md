# MediCare+ Final - Backend Spring Boot

Ce dossier contient le backend final ajoute sur une branche separee pour ne pas modifier le projet principal du depot.

## Contenu

- `backend/`: API Spring Boot MediCare+.
- `docs/screenshots/`: captures du rendu du projet.
- `docs/reference-screenshots/`: captures de reference fournies pour le style visuel.

## Lancer

```powershell
cd codex-final/backend
mvn spring-boot:run
```

## Tester

```powershell
cd codex-final/backend
mvn test
```

API disponible sur `http://localhost:8080/api`.
